# Scoop bucket for MaldocTrace

```powershell
scoop bucket add maldoctrace https://github.com/debugactiveprocess/scoop-bucket
scoop install maldoctrace/maldoctrace
maldocTrace version
```

[MaldocTrace](https://github.com/debugactiveprocess/MaldocTrace) is a static analyzer and safe VBA emulator for malicious Office documents. The manifest installs the prebuilt Windows release (amd64 or arm64) and checks it against the release SHA-256.
